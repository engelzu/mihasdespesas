===========================================================
  COMO ENVIAR ATUALIZAÇÕES PARA O GITHUB VIA COMANDOS
===========================================================

Este arquivo explica exatamente o que foi feito por baixo
dos panos para enviar o seu aplicativo para o GitHub sem
precisar usar o site manualmente.

-----------------------------------------------------------
1. INSTALAÇÃO (Já foi feita no seu computador)
-----------------------------------------------------------
O programa "Git" foi instalado silenciosamente no seu 
Windows usando o comando:
> winget install Git.Git

-----------------------------------------------------------
2. O PRIMEIRO ENVIO (Já foi feito)
-----------------------------------------------------------
Para configurar o seu repositório pela primeira vez e enviar
todos os 120+ arquivos pesados de uma vez, foram executados
os seguintes comandos na pasta do projeto:

> git config --global user.name "engelzu"
> git config --global user.email "engelzu@github.com"
> git init
> git add .
> git commit -m "Initial commit Capacitor app"
> git branch -M main
> git remote add origin https://github.com/engelzu/mihasdespesas.git
> git push -u origin main

Durante o comando "push", o Windows abriu aquela janela pedindo
para você autorizar o aplicativo no seu navegador.

-----------------------------------------------------------
3. COMO VOCÊ PODE ATUALIZAR SOZINHO NO FUTURO
-----------------------------------------------------------
Como o seu projeto já está conectado à sua conta do GitHub, 
das próximas vezes que você alterar algum código ou arrumar
algum botão e quiser mandar pro GitHub (pro Appflow ver), 
você NÃO precisa fazer tudo isso de novo.

Basta abrir o seu Prompt de Comando (ou PowerShell) na pasta 
do seu aplicativo ("usuario") e digitar apenas estes 3 comandos:

1º Passo (Prepara os arquivos novos):
> git add .

2º Passo (Cria um pacote com uma mensagem):
> git commit -m "Corrigi um erro na tela X"

3º Passo (Manda direto pra nuvem):
> git push

Como você já fez o login hoje, ele vai enviar instantaneamente
sem pedir senha nenhuma!
